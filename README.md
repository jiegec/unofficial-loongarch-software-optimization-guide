# Unofficial LoongArch Software Optimization Guide

An unofficial software optimization guide for the LoongArch architecture. It
targets two out-of-order cores:

- **LA664** — Loongson-3A6000 and 3C6000/S;
- **LA464** — Loongson-3A5000 and 3C5000 families.

## Disclaimer

This is an unofficial document. It is not affiliated with or endorsed by
Loongson Technology. Microarchitectural details that the vendor does not document
are derived from public measurements and may be wrong.
